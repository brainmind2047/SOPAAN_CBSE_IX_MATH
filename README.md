# SOPAAN_CBSE_IX_MATH

Brain & Mind Academy · Sopaan Practice Series · CBSE Class 9 Mathematics (NCERT Ganita Manjari Part I and II).

Students sign in on `index.html` with a **Login ID and PIN given by the teacher** (the same lock as the Class 10 program). The chapter sheets are kept in the teacher's Google Drive and are sent only after a correct login. One attempt per login per chapter, on one device; each LO test can be submitted once.

Setup and teacher guide: **SETUP.md**. Server code: `apps-script/Server.gs`.

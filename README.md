# SOPAAN_CBSE_IX_MATH

Brain & Mind Academy · Sopaan Practice Series · CBSE Class 9 Mathematics (NCERT Ganita Manjari Part I and II).

Students sign in with Gmail on the main page (`index.html`). Each LO test can be taken once; completions are recorded in a Google Sheet ("Quiz Records"). Delete a student's row there to allow a retake.

Setup: see **SETUP.md**. Every page is a self-contained HTML file.
